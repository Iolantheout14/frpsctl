托管模式

        

          systemd 与 direct（后台）互斥：同一实例的服务只能被一种模式托管，切换时服务端会拒绝并给出切换命令。
          插件是客户端登录的单点（fail-closed）——不可达时所有客户端都无法登录，doctor 会告警。
          容器场景请用前台 serve（进程即容器主进程）。
